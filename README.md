# Portfolio Website — Abdul Kholik

Website portofolio statis yang dibuat berdasarkan informasi pada CV.

## Isi folder
- `index.html` — struktur dan konten website
- `style.css` — desain visual dan responsive layout
- `script.js` — navigasi mobile dan tahun footer

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `portfolio_website_abdul_kholik`.
3. Klik dua kali `index.html` untuk membukanya di browser.

Tidak membutuhkan database, instalasi framework, atau server backend.

## Kustomisasi
- Ubah teks profil, proyek, dan pendidikan di `index.html`.
- Ubah warna, tipografi, dan layout di `style.css`.
- Ubah interaksi navigasi di `script.js`.

Catatan: tampilan proyek Toko Buku dan Custom Ubuntu ISO pada halaman proyek adalah ilustrasi konseptual, bukan screenshot aplikasi asli. Font Google Fonts membutuhkan koneksi internet; website tetap dapat dibuka tanpa font tersebut dengan font fallback.
